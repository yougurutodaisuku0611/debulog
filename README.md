# でぶログ

Gemini APIを使って食事の写真やテキストからカロリー・栄養素を推定し、体重・体脂肪率・BMIを記録してグラフ化するWebアプリです。単一のHTMLファイルのみで動作し、GitHub Pagesでそのまま公開できます。

## 特徴

- 食事の写真またはテキストをGemini APIに送り、カロリー・糖質・脂質・塩分・GI値などを推定
- 体重・体脂肪率・BMIを記録し、週/月/年単位でグラフ化(目標ラインも表示)
- 身長・年齢・性別・活動レベルから基礎代謝(BMR)を計算し、運動記録と合わせて消費カロリーを表示
- 目標体重・目標日を設定し、進捗を自動計算
- 家族や友人と共有する場合のためのプロフィール切り替え機能
- サーバー不要。データはすべてブラウザのlocalStorageに保存されます

## 使い方(利用者ごとの準備)

1. [Google AI Studio](https://aistudio.google.com/apikey) にアクセスし、無料のGemini APIキーを発行する
2. アプリを開き、右上の⚙(設定)からAPIキーを入力して保存する
3. 「目標」タブで身長・年齢・性別・活動レベル、目標体重などを入力する
4. 「食事」タブから食事を記録、「運動」タブから運動を記録、「体重」タブから体重を記録する

**注意**: APIキーはその端末のブラウザにのみ保存されます。他の端末では別途キーの入力が必要です。また、Gemini APIの無料枠には利用回数の上限があります。上限に達した場合は時間を置くか、有料プランへの切り替えを検討してください。

**モデルについて(2026年8月時点)**: Googleは2026年7月以降、旧世代モデル(`gemini-2.5-flash`など)を新規ユーザー向けに順次廃止しています。本アプリは後継モデルの`gemini-3.6-flash`(標準・無料枠あり)と`gemini-3.5-flash-lite`(軽量)を既定の選択肢にしています。`gemini-3.7-flash`(最新)も選択できますが、無料枠での提供状況が変動しやすいため、404エラーが出る場合は設定画面で別モデルに切り替えてください。Googleは今後もモデルを頻繁に入れ替えるため、エラーが出た場合は[Gemini APIの公式モデル一覧](https://ai.google.dev/gemini-api/docs/models)で最新のモデルIDを確認し、設定画面のモデル選択に反映してください。

## GitHub Pagesでの公開手順

1. GitHubで新しいリポジトリを作成する(例: `diet-tracker`)
2. このフォルダ内の `index.html` をリポジトリのルートにコミット・プッシュする
   ```bash
   git init
   git add index.html README.md
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```
3. GitHubリポジトリの `Settings` → `Pages` を開く
4. `Source` を `Deploy from a branch` に設定し、ブランチを `main`、フォルダを `/ (root)` にして保存する
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリにアクセスできるようになります

家族や友人に使ってもらう場合は、このURLを共有し、それぞれが自分のGemini APIキーを各自のブラウザに設定してもらってください。

## データの扱いについて

- 食事・運動・体重の記録、APIキー、目標設定はすべて**ブラウザのlocalStorage**に保存されます(サーバーには送信されません)
- Gemini APIへの通信のみ、入力した食事内容・画像がGoogleに送信されます。無料枠ではデータがモデル改善に利用される場合があるため、機密性の高い情報の入力は避けてください
- 端末やブラウザを変えるとデータは引き継がれません。バックアップ機能が必要な場合は追加開発をご相談ください
